## 第 1 点：两阶段优化中的策略选择机制

> **说明**：论文中 3 种策略（错峰起飞、速度调整、局部改航）在两个阶段均有使用，但侧重点不同。

### 论文中两阶段的策略分布

| 阶段 | 优化方式 | 错峰起飞 | 速度调整 | 局部改航 |
|------|----------|:---:|:---:|:---:|
| 阶段 1（FATA） | 关键航班**同步**优化 | ✅ **主要使用** | ✅ 少量 | ❌ |
| 阶段 2（独立匹配 [6]） | 为每个冲突**独立匹配**策略 | ✅ 少量 | ✅ 少量 | ✅ **主要使用** |

论文第 4.3.2 节原文：
> "第 1 阶段**错峰起飞策略**占比较多，而第 2 阶段**局部改航策略**占比较多"

### 阶段 1：FATA 全局同步优化（关键航班）

论文第 3.2.1 节原文：

> "通过关键飞行计划识别，可以得到 l 条关键飞行计划集合 {r₁, r₂, …, rₗ}。对此集合中**每个飞行计划分配一个具体的策略和决策变量**，对其进行**同步求解**，可以大幅减少潜在冲突数量。"

| 特征 | 说明 |
|------|------|
| 优化对象 | 前 10% 关键航班（Collective Influence 排名） |
| 优化方式 | 改进 FATA 算法**同时**优化所有关键航班 |
| 决策变量 | $t_{ATD}$（实际起飞时间）、$v_{ijk}$（飞行速度）、$(x_B, y_B, z_B)$（改航路径点） |
| 策略使用 | 三策略均可使用，实际以**错峰起飞为主** |
| 搜索空间 | **连续实数空间**（见表 3 取值范围） |

#### 阶段 1 不做"A vs B"的选择

论文中 FATA 对关键航班进行**全局同步优化**——不存在"冲突双方选谁调"的问题：

```
FATA 将 l 条关键航班的决策变量编码为一个联合向量：
    解向量 = [tᴬᵀᴰ₁, tᴬᵀᴰ₂, ..., tᴬᵀᴰₗ, v₁, v₂, ..., vₗ]
              ←─ l 个起飞时间 ─→  ←─ l 个速度 ─→

每个候选解同时赋予所有关键航班各自的策略+参数 →
    全局评估冲突数和运行成本 →
        FATA 在连续空间中搜索联合最优
```

**当关键航班 A 和 B 存在冲突时**：

- 若 A 和 B **都是关键航班** → FATA 同时优化两者的 $t_{ATD}$ 和 $v$，找到联合最优解
- 若只有 A 是关键航班 → 仅优化 A，B 留到阶段 2 的独立匹配策略处理
- 若**都不是**关键航班 → 完全由阶段 2 处理

这与阶段 2 的"独立匹配策略 [6]"形成互补：阶段 1 处理大规模耦合冲突（全局同步），阶段 2 处理孤立冲突点（逐点匹配）。

### 阶段 2：独立匹配策略（孤立冲突点）

论文第 3.2.1 节原文：

> "此时可以再次对此集合中的**每一个冲突点**进行局部优化，通过对每一个冲突点运用**独立匹配策略 [6]**，再次进行求解，最终得到较少冲突甚至无冲突的飞行计划。"

| 特征 | 说明 |
|------|------|
| 优化对象 | 阶段 1 后剩余的孤立冲突点 |
| 策略选择方式 | **独立匹配策略 [6]**——为每个冲突自适应分配最优策略 |
| 策略使用 | 三策略均可使用，实际以**局部改航为主** |
| 核心原因 | "局部改航策略在小范围空间维度进行解脱，对单个飞行计划整体影响更小，可有效减小多米诺效应" |

### 参考文献 [6] 的独立匹配策略（Pang et al., NTU）

| 特征 | 说明 |
|------|------|
| 全称 | Adaptive Decision Making (ADM) for Strategy Allocation |
| 机制 | **概率选择矩阵**，每代根据主导种群表现更新策略分配概率 |
| 更新公式 | $P_{update} = (1 - \eta) \cdot P_{update} + \eta \cdot \frac{N_{dominant}}{N_{total}}$ |
| 处理方式 | **所有冲突并发处理**（非串行） |
| 求解算法 | ISFS（改进随机分形搜索） |
| 策略分配 | 每冲突分配一种策略（三选一），不组合使用 |

## 第 2 点：决策变量的连续空间搜索

### 论文中的决策变量定义

论文第 3.1.1 节定义了三类决策变量及其连续取值范围（表 3）：

| 决策变量 | 对应策略 | 取值范围 | 类型 |
|----------|----------|----------|:--:|
| $t_{ATD}$ | 错峰起飞 | [1, 3600] s | **连续实数** |
| $v_{ijk}$ | 速度调整 | [5, 20] m/s | **连续实数** |
| $(x_B, y_B, z_B)$ | 局部改航 | (1,60), (1,60), (1,4) | **离散整数** |

### FATA 连续优化特性

论文第 3.2.2 节描述 FATA 的搜索机制：

- **佳点集初始化**：用数论方法在连续空间中均匀生成初始种群
- **光过滤原理 (MLF)**：基于定积分评估种群品质，控制全局搜索
- **光传播策略 (LPS)**：结合三角函数模拟光折射/全内反射，更新个体位置
- **搜索方式**：在 $[Lb, Ub]$ 连续区间内自由探索，不限于固定离散值

### 三策略协同

论文第 3.1.1 节原文：

> "这 3 种策略可以**单独使用**，也可以**结合使用**，以应对不同类型的冲突和运行环境。在实际应用中，通过优化算法，如遗传算法或粒子群算法，可以综合运用这些策略，找到最优的飞行计划调度方案。"

## 第 3 点：论文的实验结果（零冲突消解）

### 初始条件

论文第 4.1.2 节：

| 指标 | 论文数值 |
|------|:------:|
| 飞行计划数 | 100 |

| 不确定性冲突 | **97 个** |

### 优化结果

论文第 4.3.2 节原文：

> "无论使用何种优化算法，在 **30 次的运行中均能获得无潜在冲突的飞行计划**。"

| 指标 | 论文数值 |

| 最终冲突 | **0**（30 次全部消解） |
| 被调配航班数 | **24 架** |
| 使用变速策略 | **4 架**（约 17%） |
| 其中加速 | 3 架 |
| 其中减速 | 1 架 |
| 两阶段总空中时间变化 | **−181 秒**（整体加速趋势） |

│       ▼
